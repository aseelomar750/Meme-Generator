# Meme Generator Web Application

This repository contains a fun and easy-to-use meme generator web application.

## Functionality

The application allows you to create your own memes by providing:

1.  An Image URL: The base image for your meme.
2.  Top Text: The text that will appear at the top of the image.
3.  Bottom Text: The text that will appear at the bottom of the image.

Once you provide these inputs, the application will generate a meme image for you to share and enjoy!

## Deployment

This application is deployed and accessible via GitHub Pages.
